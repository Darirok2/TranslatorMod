TranslatorMod — Автоматический переводчик модов для Minecraft
Этот инструмент — Python-скрипт для автоматического перевода файлов локализации в модах Minecraft. Он работает с .jar-файлами модов, поддерживает Forge, Fabric, NeoForge, Quilt и другие загрузчики, а также любые версии Minecraft (от 1.5.2 до 1.21+). Скрипт находит файлы локализации (.json или .lang), переводит их на выбранный язык с помощью Google Translate (бесплатно, с обходом лимитов через батчи и задержки) и сохраняет переведённые моды в отдельную папку.
Поддерживает перевод с любого языка (если не английский — использует автоопределение), но предпочитает en_us/en_US как источник. Если английской локализации нет — берёт первую подходящую.
Возможности

Выбор языка перевода в консоли (например, ru → ru_ru.json / RU_RU.lang).
Поиск локализаций по всему .jar (не только в assets/*/lang).
Обработка старых (.lang) и новых (.json) форматов с правильными именами файлов.
Защита от лимитов Google: батчи по 20 строк, задержки, повторные попытки.
Использование системной временной папки для распаковки.
Не перезаписывает существующие файлы локализации.

Требования

Python: 3.8+ (рекомендуется 3.10+ для стабильности).
Библиотеки: deep_translator (для перевода).
ОС: Windows, Linux, macOS (скрипт кросс-платформенный).
Для компиляции: PyInstaller (если хотите создать исполняемый файл).

Установка

Установите Python с официального сайта.
Создайте виртуальное окружение (опционально, но рекомендуется):textpython -m venv venv
venv\Scripts\activate  # На Windows
source venv/bin/activate  # На Linux/macOS
Установите зависимости из requirements.txt (если у вас есть файл):textpip install -r requirements.txtИли вручную:textpip install deep_translator

Как использовать как Python-скрипт

Скачайте скрипт translator.py (или весь репозиторий).
Создайте папку mods рядом со скриптом и положите туда .jar-файлы модов.
Запустите скрипт:textpython translator.py
В консоли введите код языка (например, ru для русского, uk для украинского, de для немецкого). По умолчанию — ru.
Дождитесь завершения. Переведённые моды появятся в папке translated_mods.

Пример вывода в консоли
textВведите код языка (ru, uk, pl, de...): ru
Целевой язык: ru
Переведен JSON: temp/.../assets/modid/lang/en_us.json → .../ru_ru.json
Мод переведен: mods/example-mod-1.20.jar → translated_mods/example-mod-1.20.jar
Настройка скрипта (опционально)

Откройте translator.py в текстовом редакторе.
Измените константы: BATCH_SIZE (размер батча), SLEEP_BETWEEN_BATCHES (задержка в секундах), папки MODS_FOLDER и OUTPUT_FOLDER.
Добавьте больше языковых маппингов в get_full_lang_code для редких языков.
